# PWKfastwork - Modern Job Portal Platform (Fastwork Style)

ระบบเว็บหางานและจับคู่แรงงานอัจฉริยะ ออกแบบสไตล์ **Fastwork** รองรับการใช้งาน 4 บทบาทหลักอย่างสมบูรณ์แบบ พร้อมระบบฐานข้อมูล SQLite (Prisma ORM) และ UI ที่ทันสมัย Responsive ทั้งคอมพิวเตอร์และมือถือ

## 🛠 วิธีเริ่มใช้งานระบบ

### 1. วิธีคลิกเพื่อรันอัตโนมัติ
- ดับเบิ้ลคลิกไฟล์ `run.bat` ที่โฟลเดอร์ `projects/PWKfastwork1/run.bat`
- ระบบจะเปิดเบราว์เซอร์เข้าสู่ `http://localhost:3001` โดยอัตโนมัติ

### 2. หรือรันผ่าน Terminal
```bash
cd projects/PWKfastwork1
npm run dev
# หรือสำหรับการรัน Production Server:
npm run start
```

## 🌟 ฟังก์ชันหลักตามบทบาท (Key Features)

### 1. ฝั่งผู้หางาน (Job Seeker)
- **Fastwork-Style Landing Page:** หน้าแรกค้นหางาน หมวดหมู่ยอดนิยม งานด่วน งานเด่น
- **Job Search & Filters:** ค้นหาตามคำค้นหา, หมวดหมู่ (Web & Programming, Design, Marketing, Data & AI, Sales), ช่วงเงินเดือน, รูปแบบงาน (Full-time, Part-time, Contract, Internship, Freelance)
- **Application Flow:** กดปุ่มสมัครงาน แนบลิงก์ Portfolio, ประวัติ, เงินเดือนที่คาดหวัง และข้อความแนะนำตัว
- **Seeker Dashboard:** หน้าติดตามสถานะการสมัครงาน (รอดำเนินการ, นัดสัมภาษณ์, ผ่านการคัดเลือก, ไม่ผ่าน)
- **Profile Management:** ปรับปรุงข้อมูลส่วนตัว ทักษะ สถาบันการศึกษา และสถานะการทำงาน

### 2. ฝั่งบริษัท (Company)
- **Company Dashboard:** ดูสรุปประกาศงานที่เปิดรับ และจำนวนผู้สมัครทั้งหมด
- **Post New Job:** แบบฟอร์มลงประกาศงานละเอียด ระบุคุณสมบัติ สวัสดิการ ช่วงเงินเดือน สถานที่ทำงาน
- **Application Review:** ตรวจสอบประวัติผู้สมัครแต่ละตำแหน่ง พร้อมปุ่มอัปเดตสถานะ (รับพิจารณา / นัดสัมภาษณ์ / ตอบรับ / ปฏิเสธ)
- **Job Status Control:** ปิดรับสมัครชั่วคราว หรือเปิดรับสมัครใหม่ได้ทันที

### 3. ฝั่งมหาวิทยาลัย (University)
- **Employment Tracking:** ตรวจสอบและติดตามสถานะบัณฑิต/นักศึกษา (มีงานทำแล้ว, ฝึกงาน, กำลังหางาน)
- **Student Management:** เพิ่มข้อมูลนักศึกษา รหัสนักศึกษา คณะ สาขาวิชา ปีที่จบ และบริษัทที่เข้าทำงาน
- **Analytics & Stats:** แดชบอร์ดสรุปเปอร์เซ็นต์อัตราการได้งานทำ (Employment Rate) แยกตามคณะและปีการศึกษา

### 4. ฝั่งแอดมิน (Admin)
- **Overview Dashboard:** สถิติจำนวนผู้ใช้งานทั้งหมดแยกตามบทบาท, จำนวนตำแหน่งงาน, จำนวนใบสมัคร
- **User Management:** รายชื่อผู้ใช้ทั้งหมดในระบบ พร้อมปุ่มระงับการใช้งาน (Suspend) หรือเปิดใช้งาน (Active)
- **Job Moderation:** ตรวจสอบประกาศงานทั้งหมดในระบบ ลบประกาศที่ไม่เหมาะสม
- **System Logs:** ติดตามประวัติการดำเนินการของระบบ
