# LuLu The Piggy 3D Model Directory

Place your custom 3D model file here as `lulu.glb`:

```
frontend/public/models/lulu.glb
```

When this file is present, **Agent Office** will automatically load it on startup and apply it across all 9 agent workstations and the courier pig!

---

## Where to Find LuLu The Piggy 3D Models

1. **Cults3D & Printables (Fan Art 3D Print Models)**:
   - Search: `LuLu the Piggy` or `canned pig` or `LuLu pig`
   - Common formats: `.stl`, `.obj`

2. **Sketchfab**:
   - Search: `cute pig` or `chibi pig`
   - Filter by: **Downloadable**
   - Format: Select `.glb` or `.gltf`

---

## How to Convert STL / OBJ to GLB

If your model is an `.stl` or `.obj` file:
1. Open Blender (Free) -> File -> Import -> STL/OBJ -> File -> Export -> glTF 2.0 (.glb)
2. Or use a free online converter such as **Aspose 3D Converter** or **gltf-viewer.donmccurdy.com**.
3. Name the exported file `lulu.glb` and place it in this folder.
